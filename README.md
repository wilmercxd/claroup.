# 🛡️ Claro UP Sales Toolkit

**Kit de Ventas Interactivo para Seguro Celular Claro UP**

Una herramienta educativa y comercial completa para agentes TMK de Conexiones Digitales BPO. Diseñada para acelerar la capacitación, guiar el ofrecimiento y garantizar el cierre de ventas de Claro UP.

---

## 📋 Características

### 🏠 Inicio
- Reglas de oro del vendedor
- Estadísticas clave de impacto
- Filosofía comercial del producto
- Quick facts: hurto cada 5 min, desde $534/día

### 🛡️ Producto
- Coberturas detalladas (hurto, daño físico, falla eléctrica)
- Exclusiones claras (pérdida, descuido, daño cosmético)
- **Tabla de primas interactiva** con detalles y comisiones reales
- Comparativa vs competencia (Movistar, Éxito, Falabella)

### 🎙️ Guiones
- **4 guiones completos** listos para usar en secuencia:
  1. Apertura gancho (post-venta terminal)
  2. Pitch de 30 segundos (beneficios)
  3. Cierre y registro de datos
  4. Cierre legal (habeas data obligatorio)
- Botón de copiar para cada guion
- Tips tácticos específicos

### 💬 Objeciones
- **Playbook con 7 objeciones comunes:**
  - "No me interesa"
  - "Es muy caro"
  - "Ya tengo seguro"
  - "Déjeme pensarlo"
  - "Los seguros nunca pagan"
  - "Soy cuidadoso"
  - "El deducible es mucho"
- Múltiples enfoques de respuesta por objeción
- Guiones copiables

### 💰 Comisiones
- **Calculadora interactiva** de ingresos
- Selecciona rango de precio del equipo
- Desliza cantidad de ventas mensuales
- Visualiza ganancia total en tiempo real
- Tabla de comisiones por prima

### ⚙️ Proceso (Backoffice)
- Paso a paso activación en sistema AC
- 10 pasos claros y ordenados
- Datos clave para el cliente
- Líneas de siniestro, web, cancelación

## 🚀 Cómo Usar

### Opción 1: En Claude (Recomendado)
1. Abre [Claude.ai](https://claude.ai)
2. Pega el código del archivo `ClaroUpSalesKit.jsx`
3. Claude renderizará la herramienta interactiva
4. ✅ Lista para usar en navegador

### Opción 2: En Tu Proyecto React
```bash
# Instalar dependencias
npm install

# Copiar el componente a tu proyecto
cp ClaroUpSalesKit.jsx src/components/

# Importar y usar
import ClaroUpSalesKit from './components/ClaroUpSalesKit';

export default function App() {
  return <ClaroUpSalesKit />;
}
```

### Opción 3: Como Página Web
```bash
npm install
npm run dev
# Abre http://localhost:5173
```

## 📱 Información del Producto

### ¿Qué Cubre?
✅ Hurto y hurto calificado (40% deducible)  
✅ Daño físico por caídas (25% deducible)  
✅ Falla eléctrica/mecánica post-garantía (25% deducible)  

### ¿Qué NO Cubre?
❌ Pérdida, descuido, desaparición misteriosa  
❌ Daño cosmético  
❌ Uso abusivo del equipo  

### Beneficios Clave
- 2 siniestros cubiertos en 12 meses
- Reemplazo de equipo en 2-5 días hábiles a domicilio
- Equipo remanufacturado con 1 año de garantía
- Cancelación sin permanencia
- 5 días para retractarse

## 🎓 Tips de Oro para Vendedores

1. **Ofrece después de cerrar el terminal** — El cliente está en clima de compra
2. **Habla en costo diario** — "$534/día" > "$16.000/mes"
3. **Usa el modelo del equipo** — "Proteger tu iPhone 15" > "Proteger tu celular"
4. **Hurto es el gancho** — "En Colombia roban 1 celular cada 5 minutos"
5. **Cierra con facilidad** — "Sin permanencia, cancelas cuando quieras"
