## 🚀 Opción 2: Desplegar en Internet (5 minutos)

### En Vercel (Recomendado)

1. **Crea cuenta en [vercel.com](https://vercel.com)**
2. **Fork este repositorio en GitHub**
3. **En Vercel:** "Add New Project" → selecciona tu fork
4. **Click Deploy**
5. **Tu URL:** `https://tu-nombre.vercel.app` ✅

### En Netlify

1. **Crea cuenta en [netlify.com](https://netlify.com)**
2. **"New site from Git"** → autoriza GitHub
3. **Selecciona tu fork** → Deploy automático
4. **Tu URL:** `https://tu-sitio.netlify.app` ✅

## 💻 Opción 3: Desarrollo Local (10 minutos)

```bash
# 1. Clonar repositorio
git clone https://github.com/tu-usuario/claro-up-sales-toolkit.git
cd claro-up-sales-toolkit

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev

# 4. Se abre automáticamente en http://localhost:5173
```

Para cambiar código:
- Edita `ClaroUpSalesKit.jsx`
- El navegador se actualiza automáticamente
- Tus cambios aparecen en tiempo real

## ❓ Preguntas Frecuentes

### P: ¿Funciona sin internet?
**R:** Si lo descargas local con `npm install` + `npm run dev`, sí. La versión en línea (Vercel/Netlify) requiere internet.

### P: ¿Puedo modificarlo?
**R:** Sí. Es MIT License. Puedes modificar, compartir y distribuir. Solo mantén el crédito.

### P: ¿Funciona en móvil?
**R:** Sí, es completamente responsive. Guarda la URL en favoritos.

### P: ¿Dónde reporto bugs?
**R:** Abre un Issue en GitHub con descripción clara.

### P: ¿Cómo agrego nuevas objeciones?
**R:** Edita el array `OBJECTIONS` en `ClaroUpSalesKit.jsx`. Copia una existente y modifica.

### P: ¿Mi jefe necesita acceso?
**R:** Comparte el link de Vercel/Netlify o envíale `ClaroUpSalesKit.jsx` para abrir en Claude.
